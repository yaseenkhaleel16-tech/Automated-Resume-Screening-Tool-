# Automated Resume Screening Tool

A Python-based tool for automated resume screening and candidate evaluation.

## Features

- Resume screening
- Skill analysis
- Candidate evaluation
- Screening results

## Technologies

- Python
- Pandas
- Streamlit

## Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
